# generateMomentAnnotations（AI 点评）

根据打卡记录生成周/月/年 AI 点评（详细 + 周为「本周整体概括」、月/年为简要点评），写入 `momentAnnotations`，供分享海报等使用。

## 401 鉴权失败说明

若云函数日志出现 **`Request failed with status code 401`** 或 **`TcbError: ... 401`**，表示调用腾讯混元大模型时鉴权失败，需在控制台完成配置：

1. **开通云开发「大模型」扩展**  
   微信开发者工具 → 云开发 → 设置 → 扩展能力 → 开通「大模型」扩展（并绑定腾讯云账号/混元服务）。

2. **开通腾讯混元服务**  
   若扩展要求单独开通：  
   [腾讯云混元控制台](https://console.cloud.tencent.com/hunyuan) 开通混元大模型，并确保当前云开发环境已与该账号/资源绑定。

3. **检查环境**  
   确认当前云函数所在环境已开通上述扩展，且无欠费、未禁用。

完成上述配置后重新部署云函数并再次调用即可。401 期间接口会返回兜底文案（如「本周共 N 条打卡，坚持得很好～」），业务可正常使用，仅点评为固定话术而非 AI 生成。

**模型说明**：扩展支持的混元模型为 `hunyuan-turbos-latest`（及 `hunyuan-2.0-thinking-20251109`）。若使用不支持的模型名（如 `hunyuan-vision-1.5-instruct`）也可能导致 401，本云函数已统一改为 `hunyuan-turbos-latest`。

## 超时（-504003 / statusCode 433）

调用大模型通常需要 **3～10+ 秒**，云函数默认超时只有 **3 秒**，到点会被强制结束（你看到「AI点评 成功」但随后 Result: timed out，就是因为大模型在 3.1 秒返回时函数已被平台终止）。

**必须手动在控制台把该云函数的超时时间改为 60 秒**（当前微信开发者工具「上传并部署」不会自动应用本目录下 config.json 里的 timeout）：

1. 打开 **微信开发者工具**，顶部菜单 **云开发** 进入云开发控制台。
2. 左侧选 **云函数**，在列表里点 **generateMomentAnnotations**。
3. 在云函数详情里找到 **配置** / **函数配置**，把 **「执行超时时间」** 从 3 秒改为 **60** 秒，保存。
4. 若在 **腾讯云控制台** 使用：登录 [腾讯云 CloudBase](https://console.cloud.tencent.com/tcb) → 云函数 → 找到 `generateMomentAnnotations` → 函数配置 → 超时时间改为 60 秒 → 保存。

改完后无需重新上传代码，直接再试一次「生成点评」即可。
